# Smart Expense Tracker
Expense Tracker is a web-based application designed to help users efficiently manage and monitor their daily financial activities. The system allows users to record expenses, categorize transactions, and gain insights into their spending habits through a simple and intuitive interface.

⸻

🚀 Features

* 📊 Add, edit, and delete expenses
* 🗂️ Category-based expense management (Food, Travel, Bills, etc.)
* 📅 Date-wise tracking of transactions
* 📈 View total and summarized expenses
* ⚡ Lightweight and fast performance
* 🎯 User-friendly interface

⸻

🛠️ Tech Stack

* Backend: Python, Flask
* Database: SQLite
* Frontend: HTML, CSS, Bootstrap
* Version Control: Git & GitHub
